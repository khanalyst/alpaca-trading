# Current implementation map

This file is retained because older links and documentation checks point here.
The former batch plan is superseded by the current code and by
[`../../MAIN_REPO_REVIEW_PLAN.md`](../../MAIN_REPO_REVIEW_PLAN.md).

The implemented path is:

```text
journal snapshots
  → replay/G2
  → immutable decision ledger
  → isolated shadow variants
  → forward qualification and family correction
  → qualification event
  → reviewed content-addressed T3 packet
```

The adaptive path adds bounded registered numeric proposals, proposal locks,
history, exact first-class variant IDs, and one adaptive setting per strategy
in a cycle. Durable findings are stored in schema 8. The remaining boundary is
reviewed registry/config approval; evidence does not silently switch live
capital.

Use [`../../OPERATIONS.md`](../../OPERATIONS.md) for commands and
[`../HYPOTHESES_AND_VARIANTS.md`](../HYPOTHESES_AND_VARIANTS.md) for current
identities and values.
