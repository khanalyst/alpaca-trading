The former batch plan is archived. Current implementation and commands are in
[`../../README.md`](../../README.md), [`../../SETUP.md`](../../SETUP.md), and
[`../../OPERATIONS.md`](../../OPERATIONS.md). Strategy identities and values

evidence rules are in [`../protocol.md`](../protocol.md).

The historical path was one demo order lane plus four deterministic realtime
research lanes; three registered long-horizon models remained offline-only.
The current implementation supersedes its baseline-plus-one rotation with one
shared baseline and a bounded pre-registered candidate batch (four shipped,
hard cap eight per lane). Each assignment still tests one setting and produces
immutable terminal outcomes and research-only edge evidence. Replay/G2,
forward qualification, and reviewed T3 packets remain stricter evidence
tooling; none changes configuration or authorizes live capital. Findings are
durable in schema 16.
